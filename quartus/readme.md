# Descrição de cada arquivo do diretorio:
 ## mega_memory.qpf (Quartus Project File) 
 Responsavel por abir o projeto diretamente no Quartus.

 ## mega_memory.qsf (Quartus Settings File) 
 É o responsavel por guardar as informacoes do projeto como o modelo
 da placa, o mapeamento dos pinos no Pin Planner e as opcoes do compilador. 

 ## mega_memory.cmp (Component Declaration File)
 Armazena a declaração da estrutura **component mega_memory**

 ## mega_memory.ipinfo (IP Information File)
 Arquivo de metadados do MegaWizard responsavel por mapear, validar e 
 inicializar o conteúdo estático do mecanismo IPDRC (IP Design 
 Rule Check ou Verificação de Regras de Design de IP) do Quartus.
